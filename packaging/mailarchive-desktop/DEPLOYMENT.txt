Notes:
- The dashboard and reader run under one process and bind loopback only; a
  non-loopback bind is refused. Each Windows account (and each sign-in session of it)
  runs its own instance; a second launch of the same account reconnects to it after
  the instance proves itself, and a launch that finds a running instance with another
  configuration says so in a dialog.
- "Copy MailArchive link" (Start Menu) shows a fresh private link in a dialog with a
  Copy button, for a default browser that cannot be opened.
- Upgrading ends running mailarchive-desktop.exe instances (Install-RMM.ps1 and the
  MSI do), so the new version takes effect in every session at once.
- The weekly backup runs the engine headless (never the dashboard UI), so it fires
  whether or not the dashboard is open. It reuses the saved device sign-in.
- mailarchive.exe is also bundled for app-only / multi-mailbox scheduled graph
  captures and headless CLI use.
- Uninstall preserves the mail archive, %LOCALAPPDATA%\MailArchiveDesktop, and the
  Credential Manager sign-in. Use Cleanup-CurrentUser.ps1 for full deprovisioning.
