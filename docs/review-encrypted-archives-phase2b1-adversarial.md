# Adversarial pass — encrypted archives slices 2b-0 and 2b-1

**Reviewed commit:** `050b670` (branch `encrypted-archives`)
**Date:** 2026-10-25
**Gate:** the finder/skeptic procedure (`../assurance-kit/process/adversarial-review.md`) for a
security-sensitive change: the sealed record (`internal/container`), its inventory and the F12 rule, and
their wiring (`internal/app`, `internal/export`, `internal/state`, `internal/vault`, `internal/assure/leak`).
**Run:** workflow `phase2b-1-adversarial` (`wf_4492cc54-4a7`, 9 agents): five read-only finders with
distinct lenses — OUT (an attacker who can rewrite the archive folder), CON (crashes and concurrency),
LEAK (cleartext), FC (fail-closed consumers and the predicate), FID (fidelity and test strength) — each
proving its claims with failing tests in its own scratch copy; three refutation-default skeptics who
reproduced every confirmed finding against an unmodified copy of `050b670`; one completeness critic.
Tool versions: Go 1.26.0.
**Tallies:** 28 found / **23 confirmed** (2 medium, 21 low) / 5 refuted; the critic proved 3 more
(CRIT-1, CRIT-2, CRIT-3 with its consequence CRIT-3b), the riskiest of the pass.

## Outcome

All confirmed findings are fixed, each with a regression test (catalog MA-755) shown red against the
pre-fix code by a mutation sweep (each fix disabled in turn); the design is amended in
`docs/design-encrypted-archives-phase2b.md` §11. The riskiest finding (CRIT-3/3b: a half-synced folder
that looks new is re-initialised and its real record later swept) is closed by two rules: a folder with
no pointer is a new archive only when nothing says it lived before; and the start sweep removes an
unnamed file only when the inventory lists it retained or a run since the record's last commit wrote it.

Residuals, stated: the CRIT-3b step "a sync tool keeps the local pointer over the remote one" was assumed,
not run against a real sync tool (a two-device lab run would settle it); the remedy date for a damaged
chunk comes from its mtime, which a folder writer can set (it only steers the advice).
