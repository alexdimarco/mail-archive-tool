#### Checked and found sound

- The scheduler writers: names are hashes; cron, plist, Task Scheduler XML and the wrapper quote or escape every argument (`%`, `!` without delayed expansion, `&`, `^`, quotes); `Spec.Validate` refuses control characters (`schedule.go:96-104`).
- Path traversal: `CleanFolderName` removes control, bidirectional, zero-width and other invisible characters; `SanitizeSegment` strips `/ \ : * ? " < > |`, trims leading and trailing dots and spaces, and neutralises `CON`, `NUL`, `COMn` and `LPTn`. So `..` and separators can never escape the parent.
- `CreateFolder` opens the parent first, compares identity, then makes the folder through the root at 0700 (`copyexport_folder.go:78-112`). It is sound for the mkdir (but see B-08, B-18).
- `archindex`'s manifest read (`os.Root`, bounded, ids read as text and never resolved; `index.go:257-319`) is the right reader for §7's ids, apart from the link at the last element (B-05). `Reconcile` adds only folders that are real archives, so a planted made-list line can do no more than writing `known-archives.json` could.
- The plan and summary dialogs pass `--no-markup` on Linux (`third_party/zenity/msg_unix.go:8`); alert headers strip CR and LF; the guard reads job files through the secure `job.Read`. `AddArchive` has no other caller (`desktop/addarchive.go:17` only).
